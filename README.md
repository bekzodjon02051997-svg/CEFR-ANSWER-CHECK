# DTM Tekshiruvchi (answer sheet real-time checker)
1. Shu papkadagi hamma narsani GitHub repo ildiziga yuklang (.github papkasi bilan).
2. Actions -> Build APK -> Artifacts -> DTM-Tekshiruvchi-APK (app-debug.apk).
3. Ilovada "Kalitlar" -> 70 ta kalitni kiriting yoki .txt yuklang.
4. Varaqni yashil ramkaga to'g'rilang. O'ng yuqoridagi rasmda yashil = to'g'ri kalit, qizil = xato belgi.
   Doiralar mos tushmasa "Sozlash" orqali siljitish/masshtabni to'g'rilang.
